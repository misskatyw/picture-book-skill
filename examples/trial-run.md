# 試跑示範 —《小晴自己刷牙仔》（2026-11-11 試跑）

呢份係用新版 Skill 由頭行一次嘅紀錄，證明問卷 → 設定 → 文字 → 試版 → 砌 PDF 成條流程行得通。
主角係虛構示範小朋友，唔係真人。

## 1. 問卷（模擬一位朋友用家填）

| 題 | 答案 |
|---|---|
| 1. 名／暱稱 | 小晴（Sunny） |
| 2. 幾歲 | 3 歲 2 個月 |
| 3. 性別 | 女仔 |
| 4. 主題 | 第一次自己刷牙 |
| 5. 語言 | C. 中＋英雙語（中文主行、加大字；英文跟尾） |
| 6. 一行上限 | 中文 12 字／行；英文 8 words／行；每頁最多 2 行／語言 |
| 7. 總頁數 | 試跑版 4 頁（封面＋3 頁）；正式版通常 11 頁 |
| 8. 畫風 | A. 溫柔水彩 |
| 9. 家庭相 | （示範）媽媽：長黑髮、冇眼鏡；小晴：黑色 bob 頭、粉紅雲朵睡衣。爸爸今次唔出場 |
| 10. 真實元素 | 粉紅雲朵睡衣、木製小凳仔 |
| 11. 輸出 | A4 橫版 PDF；有聲版：唔要 |

## 2. 人物設定表（按家庭相／形容整理，等用家確認嗰份）

- **小晴**：3 歲女仔，黑色 bob 頭（齊瀏海），粉紅色雲朵圖案睡衣，全書唔變。
- **媽媽**：長黑髮過膊，冇眼鏡，米色外套；角色：陪住、拍手鼓勵，唔代勞。

## 3. 逐頁稿（逐行數字數，冇一行超上限）

- 封面：小晴自己刷牙仔（7 字）／ Sunny Brushes Her Teeth（4 words）
- P1：呢個係小晴，三歲喇！（10 字）／ This is Sunny. She is three!（6 words）
- P2：唧少少牙膏，刷刷刷！（10 字）／ A little toothpaste. Brush, brush!（5 words）
- P3：刷完牙，白雪雪，好開心！（11 字）／ All done! Clean, white, happy!（5 words）

故事結構照 Skill：出場 → 自己試（慢少少都得）→ 成功一小步 → 媽媽攬住開心收尾。

## 4. 畫風試版

封面先生一張（溫柔水彩、冇文字入圖），對設定表：bob 頭 ✓、粉紅睡衣 ✓、
媽媽長黑髮 ✓、冇眼鏡 ✓。確認後先生 P1–P3。

## 5. 砌 PDF

用 `build_pdf_template.py`，年齡帶 3-4 → 內文中文 **24pt**／英文 **23pt**
（舊版 19／13.5），封面中文 **48pt**／英文 **38pt**（舊版 42／22）。
試跑成品 PDF 由上述設定砌成（封面＋3 頁，逐頁驗字通過）。
